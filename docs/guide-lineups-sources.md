# Guide-sourced lineups: source log

Accessed: **2026-10-03**. Source: [Prydwen Institute](https://www.prydwen.gg/star-rail).

## How the teams were picked
- Each DPS's Prydwen character page has a **Teams** section. I used its Memory of Chaos tab, which lists teams ordered by Prydwen's usage rank ("Rank N", "App. rate").
- I took the first 5 complete teams (the DPS plus 3 teammates), in Prydwen's order. Teams with only 2 teammates and repeats of the same teammates were skipped. If a page had fewer than 5 complete teams, the DPS gets fewer; nothing is padded.
- Each lineup title gives the Prydwen team rank and usage rate, so you can find it on the page.

## How teammate roles were picked
Roles come from the role columns on [Prydwen's tier list](https://www.prydwen.gg/star-rail/tier-list):
- Amplifier → support
- Sustain → sustain
- Support DPS → sub-DPS
- Characters Prydwen lists only as "DPS" (Silver Wolf LV.999, Dan Heng, Hysilens, Aventurine • Waveflair) fill a sub-DPS slot in these teams, so they are tagged sub-DPS.
- Your own DPS picks keep their DPS role. Ashveil, Evernight, Gilgamesh, Kafka and Black Swan also get sub-DPS, because Prydwen lists them as Support DPS.

Name matches that weren't obvious: Prydwen "March 7th • Evernight" = Evernight (1413), "Tingyun • Fugue" = Fugue (1225). Every match was double-checked against element.
